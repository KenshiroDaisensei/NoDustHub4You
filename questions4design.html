ระบบค้นหาห้องปลอดฝุ่น (Clean Room Finder)

สรุปสิ่งที่ต้องการ (เบื้องต้น)

  1. คนทั่วไปเปิดเข้ามา → เห็นแผนที่ → หาห้องปลอดฝุ่นใกล้ตัวได้ทันที
  2. ข้อมูลมาจาก 2 แหล่ง: กรมอนามัย + คนเพิ่มเอง (ร้านกาแฟ สถานที่ต่างๆ)
  3. คนไปใช้จริง → ถ่ายรูป แชร์พิกัด เขียนรีวิวได้
  4. เข้าผ่าน LINE (สแกน QR) หรือเว็บก็ได้
  5. ต้องใช้ง่าย ไม่ยุ่งยาก
หมวด 1: การเข้าถึงและ Login
1.1
คนทั่วไปที่แค่อยาก "ดู" ว่าห้องปลอดฝุ่นอยู่ตรงไหน → ต้อง login ก่อนไหม? หรือเปิดดูได้เลยโดยไม่ต้อง login?
1.2
ถ้าจะ "รีวิว / ถ่ายรูป / เพิ่มจุด" ต้อง login → ใช้ LINE Login อย่างเดียวพอไหม? หรือต้องมี email / เบอร์โทรด้วย?
1.3
ร้านกาแฟ / สถานที่ที่อยากเพิ่มตัวเองเข้าระบบ → ใช้ login เดียวกับคนทั่วไปได้ไหม? หรือต้องแยก account ร้านค้า?
หมวด 2: แผนที่และการค้นหา
2.1
เปิดมาครั้งแรก → แสดงแผนที่ตรงตำแหน่งปัจจุบันของผู้ใช้เลยไหม? (ขอ GPS)
2.2
ค้นหาแบบไหนบ้าง?
  1. ค้นจากตำแหน่งปัจจุบัน (ใกล้ฉัน)
  2. ค้นจากชื่อจังหวัด / อำเภอ
  3. ค้นจากชื่อสถานที่ (เช่น "ร้านกาแฟ ABC")
  4. ค้นจากประเภท (ร้านกาแฟ, ห้างฯ, โรงเรียน, ฯลฯ)
  5. อื่นๆ
2.3
ต้องแสดง "เส้นทาง" นำทางไปห้องปลอดฝุ่นไหม? (เชื่อม Google Maps)
2.4
ต้องแสดงข้อมูลค่าฝุ่น PM2.5 ปัจจุบันในพื้นที่ด้วยไหม? (ดึงจาก DustBoy / Air4Thai)
หมวด 3: ข้อมูลห้องปลอดฝุ่น
3.1
แต่ละจุดบนแผนที่ ต้องแสดงข้อมูลอะไรบ้าง?
  1. ชื่อสถานที่
  2. ที่อยู่
  3. ประเภท (ร้านกาแฟ, อาคารราชการ, ฯลฯ)
  4. เวลาเปิด-ปิด
  5. รูปภาพ
  6. เบอร์โทร / ช่องทางติดต่อ
  7. ความจุ (รับได้กี่คน)
  8. สิ่งอำนวยความสะดวก (แอร์, เครื่องฟอกอากาศ, WiFi, ปลั๊กไฟ, น้ำดื่ม)
  9. ค่าใช้จ่าย (ฟรี / มีค่าใช้จ่าย)
  10. อื่นๆ
3.2
ห้องปลอดฝุ่นจากกรมอนามัย กับ ห้องที่คนเพิ่มเอง → ต้องแยกให้เห็นชัดไหม? เช่น ติดป้าย "ผ่านการรับรอง" vs "ชุมชนแนะนำ"
หมวด 4: การเพิ่มจุดใหม่ (ร้านกาแฟ / สถานที่)
4.1
ใครเพิ่มได้บ้าง?
  1. เจ้าของสถานที่เท่านั้น
  2. คนทั่วไปแนะนำสถานที่ที่เจอได้ด้วย
4.2
ต้องมี admin อนุมัติก่อนขึ้นแผนที่ไหม? หรือขึ้นเลยแล้วค่อยตรวจทีหลัง?
4.3
ฟอร์มเพิ่มจุด → กดปักหมุดบนแผนที่ได้เลย หรือพิมพ์ที่อยู่แล้วระบบหาพิกัดให้?
4.4
ต้องแนบรูปถ่ายสถานที่ตอนเพิ่มไหม? (บังคับ หรือ optional)
หมวด 5: รีวิวและรูปภาพ
5.1
รีวิวเป็นแบบไหน?
  1. ให้ดาว (1-5 ดาว)
  2. เขียนข้อความ
  3. ถ่ายรูป
  4. ทั้งหมดรวมกัน
5.2
ต้องมีระบบ report รีวิวไม่เหมาะสมไหม?
5.3
เจ้าของสถานที่ตอบกลับรีวิวได้ไหม?
หมวด 6: LINE Integration
6.1
LINE OA (Official Account) → ต้องมีไหม? เอาไว้ทำอะไร?
  1. แจ้งเตือนเมื่อค่าฝุ่นสูง "วันนี้ฝุ่นเยอะ หาห้องปลอดฝุ่นใกล้คุณ"
  2. แจ้งเตือนเมื่อมีห้องปลอดฝุ่นใหม่ในพื้นที่
  3. ส่งตำแหน่งใน LINE แล้วบอทตอบห้องปลอดฝุ่นใกล้เคียง
  4. แชร์ห้องปลอดฝุ่นให้เพื่อนผ่าน LINE ได้
6.2
LIFF (เปิดเว็บใน LINE) → ใช้แบบนี้เป็นหลักไหม? คือคนกดเมนูใน LINE OA แล้วเปิดเว็บขึ้นมาเลย?
หมวด 7: ขอบเขตและอนาคต
7.1
เริ่มเฉพาะเชียงใหม่ก่อน แล้วค่อยขยาย? หรือทั่วประเทศเลย?
7.2
ภาษา → ไทยอย่างเดียว หรือต้องมีอังกฤษด้วย (สำหรับนักท่องเที่ยว)?
7.3
มี admin dashboard สำหรับจัดการข้อมูลไหม? (อนุมัติจุดใหม่, ลบรีวิว, ดูสถิติ)
7.4
ต้องการระบบ analytics ไหม? เช่น สถานที่ไหนคนเข้าดูเยอะ, จุดไหนถูกค้นหาบ่อย
สามารถเพิ่มเนื้อหาและรายละเอียดได้ถ้าต้องการ (ยิ่งละเอียดและเป็นรูปธรรมเท่าไรยิ่งดี)
